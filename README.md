# Open-Source Max4Live Vector Synthesizer

This is an open-source Max4Live instrument that brings vector synthesis to Ableton Live, inspired by the capabilities of the Korg Wavestate. It provides access to 77 wavetables, each built from 63 unique samples covering a diverse range of sonic themes. These themes include whale vocalizations, water, insects, electrical hums, speech, and more, derived from an extensive sound research project.

## Sound Source & Inspiration
The sound material used in this instrument originates from a research expedition that captured one-second sound snippets continuously for ten days while hiking through the polar circle in northernmost Norway. The captured sound events were classified using YAMNet, and corresponding samples were sourced from Freesound.org to build a rich and evocative sonic palette.

## Features
- **Vector Synthesis Engine**: Blend between multiple wavetables dynamically.
- **77 Unique Wavetables**: Designed from 63 thematically categorized samples.
- **Diverse Sound Themes**:
  - Whale vocalizations
  - Water textures
  - Insect noises
  - Electrical hums
  - Speech elements
  - Many more
- **Real-Time Modulation**: Shape the sound with intuitive modulation controls.
- **Max4Live Integration**: Fully compatible with Ableton Live’s workflow.

## Installation
1. Download the Max4Live device file.
2. Open Ableton Live and drag the device onto a MIDI track.
3. Load and explore the rich collection of wavetables.

## Applications
- **Experimental Sound Design**: Create evolving textures and ambient soundscapes.
- **Electronic Music Production**: Craft unique pads, leads, and rhythmic elements.
- **Film Scoring & Game Audio**: Generate organic and cinematic sound effects.

## Open-Source & Contributions
This instrument is open-source, inviting community modifications and enhancements. Contributions such as new wavetables, interface improvements, or added functionality are highly encouraged.
